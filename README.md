# ADCOM Mérida — propuesta visual

## Estado
Propuesta HTML estática para revisar. No está publicada en Vercel, no está conectada al dominio de ADCOM y no contiene formularios ni integraciones activas.

## Qué incluye
- Inicio, servicios, portafolio y una plantilla de detalle de proyecto.
- Diseño adaptable a móvil, navegación por secciones y CTA de muestra.
- Imágenes conceptuales generadas para esta propuesta. No corresponden a obras de ADCOM.
- Campos de portafolio vacíos y rotulados para sustituir por información autorizada.

## Datos de marca usados
La propuesta conserva el nombre ADCOM Mérida, el lema “No lo sueñes, constrúyelo” y los servicios publicados: Arquitectura, Diseño, Construcción y Mantenimiento. No se añadieron teléfono, correo, redes, dominio, testimonios ni cifras sin validar.

## Revisión
Abrir `index.html` en el navegador. Antes de presentar la web como versión final, sustituir las imágenes conceptuales y los campos entre corchetes por material autorizado por ADCOM.

## Publicación
El repositorio es público. No se configuró GitHub Pages ni Vercel. La publicación en Vercel queda para cuando se apruebe esta propuesta.
